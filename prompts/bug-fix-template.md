# Cursor Bug Fix Prompt

Investigate this defect:

[Describe defect]

Before changing code:

1. Reproduce the issue.
2. Identify the exact failure path.
3. Identify the violated requirement.
4. Identify whether the defect affects privacy, authorization, consent, audit, or duplicate delivery behavior.
5. Propose the smallest safe fix.
6. List tests that will prove the fix.

Then implement the fix.

Do not refactor unrelated code.

Run relevant tests and report the actual results.
