# Phase 5 Prompt: Ward Directory and Households

Implement:

- Person list
- Person search
- Person creation and editing
- Household creation and editing
- Household membership
- Person relationships
- Multiple contact methods
- Preferred contact methods
- Consent state
- Active and inactive status
- Minor data restrictions
- Audit events

Desktop screens:

- Directory
- Person editor
- Household editor

Mobile screens:

- Search member
- View member
- Add member
- Edit permitted fields

Requirements:

- Normalize phone numbers.
- Validate email addresses.
- Do not infer consent.
- Restrict date of birth and minor contact information by permission.
- Keep household role and family relationship separate.
- Add tests for divorce, remarriage, guardianship, inactive relationships, incomplete records, and single parent households.
