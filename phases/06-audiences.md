# Phase 6 Prompt: Audience Groups

Implement configurable audience groups.

Required behavior:

- Create
- Rename
- Archive
- Delete only when safe
- Manual member assignment
- Many to many membership
- Many to many destination assignment
- Audience membership preview
- Duplicate membership detection
- Group counts
- Search and filtering
- Audit events

Do not hardcode Young Women, Young Men, Relief Society, Priesthood, Youth, Adults, or General into business logic.

Create them only as optional seed examples.

Prepare the domain for future rule based membership but do not implement a rules engine yet.
